# Replication guide

This package reproduces the revised study on explainable software defect prediction: data
preparation (step 1), the evaluation framework (2), models and experiments (3), explanations
(4), their robustness (5), fidelity (6) and stability (7), and the closing analyses and paper
assets (8). Each step has a report in `reports/` and a section in the development log of
`README.md`.

## 1. Environment

Python 3.11. Create the environment from the lock file (hashes required):

```bash
make env          # uv venv + uv pip install --require-hashes -r requirements.lock + pip install -e .
```

On macOS the processes re-execute themselves once to share a single OpenMP runtime between
PyTorch, XGBoost and scikit-learn; see `docs/ENVIRONMENT.md`. R is optional (Scott-Knott ESD
cross-check only).

## 2. Commands

| command | what it does | time (10 cores, Apple M5) |
|---|---|---|
| `make quick` | reduced run of steps 1–8 (ant and synapse, 2 seeds, 5 Optuna trials, LIME/KernelSHAP on 20 instances per split) into `results_quick/`, `reports_quick/`, `artifacts_quick/` | about 6 min (measured: 6.2 min on 10 cores) |
| `make reproduce` | full run of steps 1–8 from the raw data (downloads only missing files) | about 4.5 h wall (step 3: 2.3 h) |
| `make paper-assets` | regenerates `paper/figures/`, `paper/tables/`, `paper/numbers.tex` from the results and checks every number | about 1 min |
| `make test` | test suite | about 1 min |
| `make fresh-clone-check` | clones the repository into a temporary folder, builds the environment from the lock file, runs `make quick` and the tests there | about 20–30 min |

`python -m scripts.reproduce --mode full --steps 5 6` reruns selected steps; `--dry-run` prints
the plan with the expected runtime of each step.

## 3. What the archive contains

- source code (`src/sdp/`, `scripts/`), tests, configurations (`configs/`), the lock file;
- raw data with checksums (`data/raw/`, `MANIFEST.csv`) and their licences (`data/LICENSE-DATA.md`);
- all reports (`reports/`, including `reports/archive/step4_v1/`), the paper assets (`paper/`);
- result files: every experiment's metrics, hyperparameters, timings and run information; the
  test and validation predictions of `main_time_aware`; the summaries of steps 4–7
  (`results/`).

Not included (regenerated by `make reproduce`): the fitted models and the per-instance
attribution store (`artifacts/`, about 300 MB), and the other experiments' prediction files.
To regenerate only the attribution store after step 3: `python -m scripts.run_explanations`
followed by `python -m scripts.run_explanations --methods LIME_mean_sampling` (the kept v1 LIME
setting). The pipeline is deterministic on the recorded platform (CPU only, fixed seeds,
single-threaded workers); on other platforms the last digits may differ.
